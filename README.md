# Apteno Optics website

Static HTML5 site for GitHub Pages. The page uses relative asset paths, so it works from `https://moogert.github.io/apteno-optics/`.

## Publish

The separate repository already exists at `https://github.com/Moogert/apteno-optics`. From this directory, push the committed `main` branch with `git push -u origin main` in your own terminal. Then choose **Settings → Pages → Deploy from a branch → main → /(root)** in that repository.

The contact form opens a draft in the visitor's email app. Visitors can attach photos or videos in that app before sending. GitHub Pages alone does not receive form submissions or file uploads; a hosted form service or backend is required for that workflow.

JetBrains Mono and Fira Mono font files are self-hosted under their Open Font Licenses in `assets/fonts/`. Original HTML5 UP Landed attribution and license are retained in the footer and `LICENSE.txt`.
